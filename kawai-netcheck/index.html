Kawai Wi-Fi Network Check

このページから複数の配信先へ直接アクセスし、どこまで通信が通るかを確認します。プロキシ・VPN・中継は行いません。

自動テスト

「成功」は、そのホストまでHTTPS通信が成立したことを示します。失敗だけではDNS・TCP/TLS・フィルタのどこで止まったかを完全には断定できません。

YouTubeプレイヤー実表示テスト

下にYouTubeプレイヤーが表示され、再生操作までできるか確認してください。自動テストとは別の確認です。

診断メモ

  • Googleは成功、youtube.comだけ失敗 → YouTube本体ドメインの選択的ブロックの可能性。
  • youtube.comは成功、i.ytimg.comが失敗 → サムネイル等の画像配信先が別にブロックされている可能性。
  • YouTube系は成功、googlevideo系だけ失敗 → ページは開けても動画本体の配信経路で止められている可能性。
  • YouTube系が広く失敗し、Google系は成功 → DNS変更だけでは変わらない上位レイヤーのフィルタと整合的。
